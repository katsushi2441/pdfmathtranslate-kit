# 00 全体像とライセンスの線引き

## このキットで実現すること

英語のPDF（論文・技術文書・海外メーカーのマニュアル・仕様書）を、**レイアウト・数式・図表・引用番号を保ったまま日本語にする**仕組みを、自社サーバーに立てます。翻訳の中身を外部のクラウドに送らない構成を選べます。

土台は [PDFMathTranslate](https://github.com/Byaidu/PDFMathTranslate)（コマンド名 `pdf2zh`・AGPL-3.0・GitHubスター約36,700）です。

### 当社の実測（2026年9月・本キットの構成）

| 項目 | 実測値 |
|---|---|
| 対象 | 英語の学術論文 15ページ・2.2MB（数式・表・図つき） |
| 翻訳時間 | **179秒（約3分）／11秒・ページ** |
| 翻訳エンジン | 自社サーバーのローカルLLM（Ollama・gemma4 12B） |
| 追加費用 | **0円**（APIの従量課金なし） |
| 出力 | 日本語のみのPDFと、原文と訳文を並べた対訳PDFの2種 |
| 保持されたもの | 数式（LaTeX組版のまま）・図表・箇条書き・節番号・式番号・引用番号 |

同じ論文をクラウドの翻訳APIに投げると、文書そのものが社外に出ます。技術資料・未公開の仕様書・契約書ではそこが問題になります。本キットは、その回避を主目的にしています。

## ライセンスの線引き（先に確認すること）

PDFMathTranslate は **AGPL-3.0** です。次のように整理してください。

| やること | 可否 |
|---|---|
| 自社サーバーに置いて、自社の社員が使う | 可。ソースの公開義務は生じません |
| 改変して自社で使う | 可。同上 |
| 改変版を**社外にネットワーク越しのサービスとして提供する** | ソースコードの公開義務が生じます（AGPLの要点） |
| 本体を組み込んだ製品を再販する | AGPLの条件に従う必要があります |

**このキットが想定しているのは1行目と2行目**です。社外の利用者に翻訳サービスとして開放する場合は、AGPLの条件（改変部分を含むソースの提供）を満たすか、後述のオフライン翻訳（Argos Translate・MIT）に置き換える判断をしてください。

翻訳した**成果物のPDF**には、このライセンスは及びません。翻訳対象の原文の著作権は別途確認してください（社外の文書を翻訳して配布する場合、翻訳権は原著作者にあります）。

## 構成の全体像

```
   英語PDF
     │
     ├─ ① レイアウト解析（PDFMathTranslate）… 数式・図表・本文の領域を判定
     │
     ├─ ② 本文だけを翻訳エンジンへ
     │      ├─ 自社サーバーのローカルLLM（Ollama）← 本キットの推奨
     │      ├─ 完全オフライン（Argos Translate・MIT・GPU不要）
     │      └─ クラウドAPI（DeepL・OpenAI 等）← 文書が社外に出る
     │
     └─ ③ 元のレイアウトに訳文を流し込む
            → 日本語PDF（-mono）と 対訳PDF（-dual）
```

6. `06-serve.md` 社内に開く（GUI・常駐・更新）
