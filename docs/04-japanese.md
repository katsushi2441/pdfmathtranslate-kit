# 04 日本語で使う

## 言語の指定

```bash
pdf2zh doc.pdf -li en -lo ja -o out
```

`-li` が原文の言語、`-lo` が訳文の言語です。**`-lo ja` を忘れると中国語になります**（この道具はもともと英語→中国語向けに作られたもので、既定の出力先が中国語です）。当社が最初に踏んだ間違いです。

## 日本語フォント

初回実行時に Source Han Serif JP が自動でダウンロードされ、`~/.cache/babeldoc/fonts/` に置かれます。ログにこう出れば正常です。

```
INFO: use font: /home/<user>/.cache/babeldoc/fonts/SourceHanSerifJP-Regular.ttf
```

閉じたネットワークで使う場合は、このフォントを含む `~/.cache/babeldoc/` を事前に持ち込んでください。

## 出力される2つのPDF

| ファイル | 中身 | 使いどころ |
|---|---|---|
| `<名前>-mono.pdf` | 日本語だけ | 読むため・社内配布 |
| `<名前>-dual.pdf` | 原文ページと訳文ページが交互 | 訳の確認・原文と突き合わせる作業 |

対訳版はページ数が2倍になります（15ページ→30ページ）。**確認は対訳版、配布は日本語版**、と使い分けます。

## 一部だけ翻訳する

```bash
pdf2zh doc.pdf -li en -lo ja -p 3 -o out       # 3ページ目だけ
pdf2zh doc.pdf -li en -lo ja -p 1,3,5 -o out   # 1・3・5ページ目
```

**`-p 3` は「3ページ目だけ」で、「1〜3ページ」ではありません**。当社は最初これを取り違えて、速度の測定をやり直しました。長い文書を本番で流す前に、代表的な1ページで訳語と体裁を確認する使い方が有効です。

## 翻訳しない語を指定する

製品名・型番・社名など、訳してほしくない語は正規表現で除外できます。

```bash
pdf2zh doc.pdf -li en -lo ja -f "(MS.*|Fig\..*)" -o out
```

`-f` は数式として扱うフォント名の正規表現、`-c` は数式として扱う文字の指定です。数式が翻訳されてしまう場合、逆に本文が数式と判定されて訳されない場合は、ここを調整します。

## 保たれるもの・崩れるもの

当社が15ページの学術論文で確認した結果です。

**保たれたもの**
- 数式（LaTeX組版のまま。`MultiHead(Q,K,V) = Concat(head₁,...,headₕ)W^O` のような複雑な式も維持）
- 式番号（(1)(2)…）、節番号（3.2.3 など）
- 図・表の位置と画像
- 引用番号（[11] [24] など）
- 箇条書きの階層

**崩れやすいもの**
- 縦に細かく分かれた文字（表紙の縦書きのarXiv IDなど、1文字ずつ配置された領域）
- 2段組の段またぎの文（段の区切りで文が切れて訳されることがある）
- 参考文献リスト（英語のまま残る箇所がある。実務では問題になりません）
- スキャンした画像だけのPDF（**文字が入っていないPDFは翻訳できません**。先にOCRが必要です）

**スキャンPDFの見分け方**:

```bash
pdftotext doc.pdf - | head -c 200
```

何も出なければ画像だけのPDFです。OCRmyPDF などで文字層を付けてから翻訳してください。
