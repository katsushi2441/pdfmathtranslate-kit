# 用語集（訳語の統一）

翻訳の揺れを止めるための表です。2つの使い方があります。

1. **訳さない語**: `-f` の正規表現に入れて、原文のまま残す（型番・製品名・社名）
2. **訳語を固定する語**: LLM系エンジンのプロンプトに差し込む（`scripts/translate_with_glossary.sh`）

## 訳さない語

| 原語 | 種別 | 備考 |
|---|---|---|
| 例）MS-100X | 型番 | |
| 例）ExBridge | 社名 | |
| | | |

正規表現の例: `-f "(MS-.*|ExBridge)"`

## 訳語を固定する語

| 原語 | 訳語 | 訳してはいけない例 |
|---|---|---|
| 例）Transformer | Transformer | トランス、変圧器 |
| 例）state of the art | 最高水準 | 最新技術の状態 |
| 例）throughput | スループット | 処理量 |
| | | |

## 運用

- 最初は10語程度で始めて、翻訳結果を読んで気になった語を足していきます
- 部署ごとに分けず、**会社で1つ**にします（分けると同じ語が別々に訳されます）
- 四半期に一度、実際の訳文と突き合わせて見直します
