# 品質チェック表

翻訳した文書を配る前に確認します。機械で見る項目は `scripts/check_quality.py` が出します。

## 文書ごとの記録

| 日付 | 原文ファイル | ページ数 | 翻訳エンジン | 所要時間 | 日本語文字数 | 翻訳が抜けたページ | 判定 | 確認者 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

## 機械で見る（スクリプトが出す）

- [ ] 原文と訳文のページ数が一致している
- [ ] 日本語文字数が0のページが無い（**参考文献・図版だけのページは0でも正常**）
- [ ] 数式・式番号・引用番号が残っている

## 人が見る（抜き取り）

- [ ] 表紙・目次・見出しが日本語になっている
- [ ] 用語集で決めた訳語が守られている
- [ ] 数式が壊れていない（記号が文字化けしていない）
- [ ] 図表の中の文字が元のまま残っている（画像内の文字は翻訳対象外です）
- [ ] 2段組の段またぎで文が切れていない

## 判定

| 判定 | 意味 | 対応 |
|---|---|---|
| 合格 | そのまま配布可 | - |
| 条件付き | 一部の訳語を直せば可 | 用語集に追加して再翻訳 |
| 不合格 | 抜けや崩れが多い | エンジンの設定を見直す（`07-troubleshooting.md`） |
