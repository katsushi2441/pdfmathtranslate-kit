# 翻訳対象の棚卸し表

導入前に埋めてください。**機密区分によって使える翻訳エンジンが変わる**ので、この表が設定の根拠になります。

| 文書の種類 | 年間の件数 | 1件のページ数 | 機密区分 | 使える翻訳エンジン | 担当部署 |
|---|---|---|---|---|---|
| 例）海外メーカーの仕様書 | 120 | 20〜60 | 社外秘 | ローカルLLM のみ | 技術部 |
| 例）学術論文 | 300 | 10〜20 | 公開情報 | どれでも可 | 研究開発 |
| 例）取引先との契約書 | 40 | 5〜15 | 機密 | ローカルLLM のみ | 法務 |
| | | | | | |

## 機密区分と使えるエンジン

| 機密区分 | 意味 | 使えるエンジン |
|---|---|---|
| 公開情報 | 誰が見てもよい（公開論文・公開マニュアル） | すべて |
| 社外秘 | 社外に出さない | ローカルLLM／オフライン のみ |
| 機密 | 限られた者だけ | ローカルLLM／オフライン のみ。加えて保存先と閲覧権限を決める |

## 決めること

- [ ] 翻訳した結果はどこに保存するか（共有フォルダ／文書管理システム）
- [ ] 誰が翻訳を実行するか（各自／情報システム部が代行）
- [ ] 原文の著作権の確認（社外の文書を翻訳して配布する場合、翻訳権は原著作者にあります）
- [ ] スキャンPDFが混ざるか（混ざるならOCRの工程が別に必要）
